# EV Battery Doctor — Android starter (Alpha 0.1.0)

Профессиональная тёмная тема. Это исходный Android Studio проект, не готовый APK.

## Уже реализовано
- Kotlin + Jetpack Compose, Material 3.
- Android 8.0+ (minSdk 26), compile/target SDK 35.
- Перечень Bluetooth Classic устройств, ранее сопряжённых в Android.
- Подключение по стандартному SPP UUID.
- Базовая проверка адаптера командами ELM327: ATZ, ATE0, ATL0, ATSP0.
- Только чтение и проверка адаптера; команды изменения параметров автомобиля не отправляются.

## Пока не реализовано
- BLE и Wi-Fi транспорт.
- Активное сканирование устройств.
- Полный OBD-II, CAN multi-frame / ISO-TP и UDS.
- Профиль BMS Changan Qiyuan Q05.
- Достоверное получение SOH, напряжений ячеек, температур и PDF-отчётов.

Нельзя достоверно оценить SOH без подтверждённых параметров BMS, единиц измерения и алгоритма производителя. Не следует отображать предполагаемые значения как измеренные.

## Сборка
1. Установите Android Studio и JDK 17.
2. Откройте эту папку как проект.
3. Установите Android SDK 35, дождитесь Gradle Sync.
4. Подключите Android-телефон, сопрягите ELM327 в системных настройках Bluetooth.
5. Запустите конфигурацию `app`.

## Следующие инженерные шаги перед тестированием
- Перенести Bluetooth transport в отдельный слой и управлять соединением через ViewModel.
- Добавить стабильную очередь команд, обработку `>` prompt, тайм-ауты и тесты разных клонов ELM327.
- Добавить BLE через GATT с выбором UART-сервиса/характеристик.
- Реализовать ISO-TP и UDS только после подтверждения адресов и разрешённых диагностических запросов автомобиля.
- Проверить лицензии, безопасность данных и требования Google Play перед публикацией.


## Сборка APK через GitHub Actions (без Android Studio)

1. Создайте на GitHub новый пустой репозиторий.
2. Загрузите в него **всё содержимое этой папки** (`EVBatteryDoctor_Android`), чтобы файл `build.gradle.kts` находился в корне репозитория.
3. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
4. Выберите workflow **Build Android APK** и нажмите **Run workflow**. Также сборка запускается автоматически при push в ветку `main` или `master`.
5. Дождитесь зелёной отметки успешной сборки, откройте завершённый запуск workflow, прокрутите до **Artifacts** и скачайте `EV-Battery-Doctor-debug-apk`.
6. Распакуйте скачанный архив. Внутри будет `app-debug.apk`. Перенесите APK на телефон и установите его. При необходимости разрешите установку приложений из используемого источника.

Это **debug APK** для тестирования, не подписанный релиз для Google Play. Не публикуйте его как production-сборку.
